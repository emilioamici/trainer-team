Informativa sulla privacy · FM Training

Ultimo aggiornamento: 21 novembre 2026

FM Training è un'app web per pianificare e registrare allenamenti, usata da atleti e coach. Questa pagina spiega quali dati usa, dove restano e come puoi cancellarli.

Chi la gestisce

L'app è un progetto personale open source. Per domande o richieste sui tuoi dati apri una segnalazione su github.com/emilioamici/trainer-team/issues.

Quali dati usa l'app

  • Piani di allenamento: allenamenti, blocchi, note del coach, feedback dell'atleta (durata, distanza, RPE, sensazioni, commenti) e il nome e l'obiettivo dell'atleta.
  • Indirizzo email e nome del tuo account Google: per riconoscerti e, se sei coach, per condividere il file con l'atleta che indichi.
  • Impostazioni (tema, lingua, ruolo) e, se attivi le notifiche, l'iscrizione push del tuo dispositivo.

Non raccogliamo posizione, contatti, dati di pagamento né dati sanitari diversi da quelli che scrivi tu nei feedback. Non usiamo analytics, pubblicità o cookie di profilazione.

Dove sono salvati

  • Google Drive: ogni atleta ha un file JSON dedicato. Nella modalità Solo Atleta il file è sul Drive dell'atleta; nella modalità Coach è sul Drive del coach, condiviso con l'atleta invitato (permesso di modifica). Il coach ha inoltre un file "registro" con l'elenco dei suoi atleti.
  • Il tuo dispositivo (IndexedDB e localStorage del browser): copia locale per lavorare offline e preferenze.

Dati degli utenti Google e permessi

L'app chiede un solo permesso a Google: https://www.googleapis.com/auth/drive.file. Con questo permesso l'app può vedere soltanto i file che crea o che apri tu stesso con il selettore di Google (Picker). Non può leggere, elencare o modificare gli altri file del tuo Drive. Usa il permesso solo per creare, leggere, aggiornare e condividere i file dei piani di allenamento.

Limited Use. L'uso e il trasferimento a qualsiasi altra app delle informazioni ricevute dalle API di Google rispetta la Google API Services User Data Policy, inclusi i requisiti di Limited Use. I dati ricevuti da Google sono usati solo per offrire le funzioni dell'app visibili all'utente; non sono venduti, non sono usati per pubblicità né per addestrare modelli di intelligenza artificiale, e nessun essere umano li legge, salvo tuo consenso, per motivi di sicurezza o se richiesto dalla legge.

Server facoltativo (accesso persistente e notifiche)

Se l'app è configurata con un Worker Cloudflare, questo fa da tramite per due funzioni.

  • Accesso persistente: il Worker conserva il token di rinnovo di Google cifrato (fino a 180 giorni, cancellato al logout); all'app arriva solo un identificativo di sessione casuale.
  • Notifiche: il Worker conserva l'iscrizione push del dispositivo e, per ogni file condiviso, l'elenco delle email iscritte. Il testo delle notifiche (es. "Completato: Test 10 km") lo attraversa cifrato e non viene salvato.

Il Worker non legge né conserva i piani di allenamento, con una sola eccezione facoltativa:

  • Importazione con AI (solo coach, solo se attivata): quando scegli «Converti un file con l'AI», il file che selezioni viene inviato tramite il Worker al servizio Gemini di Google per essere trasformato in un piano. Il Worker non salva il file né il risultato; conserva solo un contatore mensile di utilizzo per account (tetto mensile). Evita di caricare file con dati sensibili di terzi senza il loro consenso.

Condivisione

I dati di un atleta sono visibili solo a chi ha accesso al suo file su Drive: l'atleta e il coach che lo ha invitato. Il coach può togliere l'accesso in qualsiasi momento dalle impostazioni di condivisione di Drive. Non vendiamo né cediamo dati a terzi. I servizi tecnici coinvolti sono Google (Drive, accesso), Cloudflare (Worker, se attivo), i servizi push dei browser (Google, Apple, Mozilla, Microsoft, per consegnare le notifiche) e GitHub (hosting dell'app).

Conservazione e cancellazione

  • Puoi eliminare i file dal tuo Drive e svuotare i dati del sito dal browser.
  • "Scollega account" nell'app chiude la sessione sul Worker e cancella il token di rinnovo.
  • Per revocare il permesso all'app: myaccount.google.com/permissions.
  • Le iscrizioni push scadono dopo 180 giorni senza uso o quando disattivi le notifiche.

Sicurezza

La comunicazione usa HTTPS. Il Worker verifica a ogni richiesta l'identità dell'utente e il suo accesso al file, e cifra a riposo i token di rinnovo. Nessun segreto è nel codice dell'app.

Minori e modifiche

L'app non è pensata per minori di 14 anni. Se questa informativa cambia, aggiorneremo la data qui sopra.

Privacy Policy · FM Training

Last updated: 21 November 2026

FM Training is a web app for planning and logging workouts, used by athletes and coaches. This page explains what data it uses, where it is stored and how you can delete it.

Who runs it

The app is an open-source personal project. For questions or requests about your data, open an issue at github.com/emilioamici/trainer-team/issues.

What data the app uses

  • Training plans: workouts, blocks, coach notes, athlete feedback (duration, distance, RPE, feelings, comments), and the athlete's name and goal.
  • Email address and name of your Google account: to recognise you and, for coaches, to share the file with the athlete you specify.
  • Settings (theme, language, role) and, if you turn on notifications, your device's push subscription.

We do not collect location, contacts, payment data, or health data other than what you write in feedback. We use no analytics, advertising or profiling cookies.

Where it is stored

  • Google Drive: each athlete has a dedicated JSON file. In Athlete-only mode the file is on the athlete's own Drive; in Coach mode it is on the coach's Drive, shared with the invited athlete (edit permission). The coach also has a "registry" file listing their athletes.
  • Your device (browser IndexedDB and localStorage): a local copy for offline use, and preferences.

Google user data and permissions

The app requests a single Google permission: https://www.googleapis.com/auth/drive.file. With it, the app can see only files it creates or that you open yourself with Google's file picker. It cannot read, list or modify any other file in your Drive. The permission is used only to create, read, update and share the training-plan files.

Limited Use. The use and transfer to any other app of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data received from Google is used only to provide the user-facing features of the app; it is not sold, not used for advertising or to train AI models, and no humans read it unless you consent, for security purposes, or where required by law.

Optional server (persistent sign-in and notifications)

If the app is configured with a Cloudflare Worker, it acts as an intermediary for two features.

  • Persistent sign-in: the Worker stores Google's refresh token encrypted (up to 180 days, deleted on logout); the app only receives a random session identifier.
  • Notifications: the Worker stores the device's push subscription and, for each shared file, the list of subscribed emails. Notification text (e.g. "Completed: Test 10 km") passes through it encrypted and is not stored.

The Worker does not read or store training plans, with one optional exception:

  • AI import (coaches only, only if enabled): when you choose "Convert a file with AI", the file you select is sent through the Worker to Google's Gemini service to be turned into a plan. The Worker does not store the file or the result; it only keeps a monthly usage counter per account (monthly cap). Avoid uploading files with third parties' sensitive data without their consent.

Sharing

An athlete's data is visible only to people with access to their Drive file: the athlete and the coach who invited them. The coach can remove access at any time from Drive's sharing settings. We do not sell or give data to third parties. The technical services involved are Google (Drive, sign-in), Cloudflare (Worker, if enabled), browser push services (Google, Apple, Mozilla, Microsoft, to deliver notifications) and GitHub (app hosting).

Retention and deletion

  • You can delete the files from your Drive and clear the site's data in your browser.
  • "Disconnect account" in the app ends the session on the Worker and deletes the refresh token.
  • To revoke the app's permission: myaccount.google.com/permissions.
  • Push subscriptions expire after 180 days without use or when you turn notifications off.

Security

Communication uses HTTPS. The Worker verifies the user's identity and their access to the file on every request, and encrypts refresh tokens at rest. No secrets are in the app's code.

Children and changes

The app is not intended for children under 14. If this policy changes, we will update the date above.
